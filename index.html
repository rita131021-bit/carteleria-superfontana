Enlace con Supabase

Ingresa las credenciales de tu proyecto de Supabase para enlazar la base de datos y Storage.

Instrucciones de Uso Local

Para inicializar tu base de datos Supabase:

  1. Crea un proyecto gratis en supabase.com
  2. Ve a la pestaña SQL Editor de Supabase, crea una consulta nueva y pega el contenido del archivo schema.sql que está en esta carpeta.
  3. En tu computadora de Windows, haz clic derecho sobre el archivo seed_supabase.ps1 y selecciona "Ejecutar con PowerShell". Introduce la URL de tu proyecto y la Service Role Key (que encuentras en Settings -> API).
  4. ¡Listo! Tu base de datos y Storage se poblarán con las 63 plantillas y el logo oficial. Copia la URL y la Anon Key pública en este formulario para conectar la aplicación.
